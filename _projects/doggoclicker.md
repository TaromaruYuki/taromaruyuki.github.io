Doggoclicker was a small clicker game for Android. It was developed in 2020 in GameMaker Studio 1.4 for Android.

Due to GMS 1.4 not having Android x64 support, there are only x32 builds of the game.

## History
---

I started on Doggoclicker around January 2020, the first developer build being compiled Jan 25, 2020. The final release build was built May 6th, 2020.

## Versions

1.0.1 - Oldest dev build
- View doesn't fill the whole screen
- One type of Doggo
- Debug image is printed
- Shop and main view are in different rooms
- Cannot spam click

1.0.2
- More debug values printed
- Auto click added
- Info bubbles added
- Spam click fixed(?)

1.0.3
- Game is now full screen
- A info button on the main screen shows a GMS error message
- Game is now all one room
- Added Doggo types (Unknown how many there are)
- Info buttons can show negative Dogecoins if you don't have enough

1.0.4
- Data now saves(?), can erase save data
- Info button fixed, can enable and disable debug mode
