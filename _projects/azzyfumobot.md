## Information

AzzyFumoBot is a custom Discord bot for a friend's [Discord server](https://discord.gg/TFXWkr8B5u).
It is developed in Rust with [Poise](https://crates.io/crates/poise).

The source code is available, but not for personal use. 
It is only provided for transparency for the members, and having a place for bug reports.

*Any copying, distributing, or modification will result in take-downs, shake-downs, or litigation.*

## Features

FumoBot has a lot of commands to let members have fun in the Discord. It includes:

- Economy
- Pets
- XP and Levels
- Games (Gambling)

## Future Plans

We plan on implementing a full RPG inside Discord. The process has started, but progress will be slow.
